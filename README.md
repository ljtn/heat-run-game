# HEAT RUN — Meridian City

> A vibecoded game made for the kids — built for fun, not for production. Play it in the browser: **https://ljtn.github.io/heat-run-game/**

A browser car-chase game in the spirit of early-2000s driving games: soft, floaty suspension, police
pursuits when you break the law, civilian traffic, a big city plus countryside, mountains, tunnels and lakes.
Pure JavaScript + Three.js (vendored in `lib/`), no build step.

## Run

```
./start.command      # serves the folder on http://127.0.0.1:8777 (or the next free port)
```

Then open the printed URL in Chrome. Hard-reload (Cmd+Shift+R) after code changes.

## Controls

W/↑ throttle · S/↓ brake/reverse · A/D steer · Space handbrake · C camera · Q/B look back · H horn ·
M map · R reset car · T time of day · N mute · Esc pause. Gamepad supported.
On phones and tablets: drag on the left half to steer; GAS / BRAKE / DRIFT on the right.

## How to play

Grab the cash bags and gold bars (look for the golden beams). Loot is worth more the higher your wanted level.
Bank it by stopping in a repair garage while nobody's watching. Get busted or wrecked and you lose what you're carrying.
